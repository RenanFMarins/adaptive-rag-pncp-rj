# Avisos de atribuição e dados de terceiros

## Software do projeto

O código-fonte e a documentação produzidos especificamente para o projeto
Adaptive RAG PNCP/RJ são disponibilizados sob a licença MIT descrita em
[`LICENSE`](LICENSE).

O projeto foi desenvolvido colaborativamente pelo Time 03 do Grande Desafio
de IA Generativa da Residência TIC/PUC-Rio/Instituto ECOA. O histórico Git
preserva a autoria das contribuições individuais.

## Dados e documentos do PNCP

Os registros de contratações, contratos, atas, planos de contratação e
documentos relacionados são provenientes do Portal Nacional de Contratações
Públicas (PNCP) e dos órgãos e entidades que publicaram as informações.

- Portal: <https://www.gov.br/pncp/>
- Dados abertos: <https://www.gov.br/pncp/pt-br/acesso-a-informacao/dados-abertos>
- Perguntas e respostas: <https://www.gov.br/pncp/pt-br/pncp/perguntas-e-respostas/>

A licença MIT deste repositório **não relicencia** dados, marcas, PDFs,
editais, normas ou outros materiais de terceiros. A reutilização desses
conteúdos deve respeitar sua fonte, os termos aplicáveis e a legislação.

O PNCP declara acesso público e disponibiliza recursos de dados abertos. A
correção, atualização e veracidade dos registros de origem permanecem sob
responsabilidade dos órgãos e entidades publicadores. Este projeto transforma
e indexa cópias para pesquisa e não representa uma fonte oficial.

## Privacidade e limitações

Snapshots públicos produzidos pelo projeto devem utilizar a política de
sanitização documentada. A pseudonimização reduz a exposição direta, mas não
equivale a anonimização absoluta. Cobertura parcial, anomalias e lacunas devem
permanecer declaradas nos manifestos de cada release.
